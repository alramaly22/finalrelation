Project Hope — Opening Video
=============================

Drop one video file here with this exact filename:

  hero.mp4

That's it. It plays automatically, muted and looping, as a subtle
(35% opacity) cinematic background behind the opening scene's text
and light animation — once the browser confirms it can actually
play the file. If the file is missing, the opening simply uses its
current gradient background instead, exactly as it does today.

Tips:
  - Keep it subtle: slow motion, low contrast, or dim footage works
    best since text sits on top of it
  - Landscape orientation, 1920x1080 is plenty — this is a background
    layer, not the focal point
  - Compress it well (H.264 mp4, ideally under 8–10MB) since it has
    to load before the opening scene is even visible
  - A short loop (5–15 seconds) that loops seamlessly reads as
    intentional; a long clip that jumps at the loop point does not
